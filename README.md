## ソフトウェア開発

LLMを実装のシーケンサとして使いながら、
**頭の中のアーキテクチャをそのままCodingするVibe感**を大切にしています。

開発するときは、前提や複数の解釈、証拠、反例、不確実な部分などをなるべく分けて考えます。

そのために、**推論・コード監査・文書整合性・外部LLM参照をそれぞれ分離した、複数の独自LLM制御系を組み合わせて**VibeCodingしています。

ひとつのLLMやひとつの評価系だけをそのまま正解にはせず、
必要に応じて別の系から見直すようにしています。

現在取り組んでいる研究開発の多くは非公開ですが、
公開できるものは少しずつ切り出して公開しています。

---

## 公開ソフトウェア

### RepoSeiri

Rust製の、リポジトリ文書を意味の面から監査するツールです。

READMEに書かれていることと、
実際にリポジトリ内で確認できる証拠を照らし合わせて、

- 言いすぎているところ
- 逆に、実装されているのに伝わっていないところ
- まだ判断できないところ

を分けて扱います。

「分からない」を勝手に「存在しない」にしないことや、
解析することと実際に変更する権限を分けることなど、
普段の開発で大切にしている考え方を形にしたものです。
