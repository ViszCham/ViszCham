## ソフトウェア開発

LLMを実装や探索のパートナーとして使いながら、
**曖昧なアイデアを、できるだけ意味を失わずコードにしていくこと**を大切にしています。

開発するときは、前提や複数の解釈、証拠、反例、不確実な部分などをなるべく分けて考えます。そのための独自のLLM制御アーキテクチャを複数刺してバイブコーディングしています。

特に、

- 観測したこと
- 推測したこと
- まだ分からないこと
- 検証できたこと
- 実際に変更してよいこと

を、ひとまとめにしないようにしています。

AIにそのまま答えを任せるというより、
**推論や検証の仕組みを挟みながら一緒に作っていく**
スタイルに近いです。

現在取り組んでいる研究開発の多くは非公開ですが、
公開できるものは少しずつ切り出して公開しています。

## 公開ソフトウェア

### RepoSeiri

Rust製の、リポジトリ文書を意味の面から監査するツールです。

READMEに書かれていることと、
実際にリポジトリ内で確認できる証拠を照らし合わせて、

- 言いすぎているところ
- 逆に、実装されているのに伝わっていないところ
- まだ判断できないところ

を分けて扱います。

「分からない」を勝手に「存在しない」にしないことや、
解析することと実際に変更する権限を分けることなど、
普段の開発で大切にしている考え方を形にしたものです。
